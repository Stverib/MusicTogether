# MusicTogether 3D 舞台 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 房间中央出现一台会随音乐转动的黑胶唱片机，低音与高音驱动周围的粒子与灯光；主题是房间级状态，谁都能切，两边一起过渡。

**Architecture:** 场景层是一个独立于 Preact 的命令式模块（`stage.ts`），自己持有 canvas / renderer / 相机 / RAF 循环，用 signals 的 `effect()` 订阅 store —— 与 `player.ts` 同一个模式。主题是「数据 + 工厂」，只负责环境（背景、灯光、粒子），唱片机由 Stage 恒定持有；切主题时新旧两个 Theme 靠 `setWeight` 交叉淡入淡出。律动数据由三层兜底的本地分析提供，绝不上行。

**Tech Stack:** TypeScript · Vite · Preact + @preact/signals · Three.js（动态 import）· Vitest（单元）· @cloudflare/vitest-pool-workers（集成）· Playwright（E2E）

**Spec:** `docs/superpowers/specs/2026-10-18-3d-stage-design.md` —— 本计划实现该规格，执行时两份文档一起读。

## Global Constraints

以下每一条都是全局要求，每个任务都隐含包含：

- **CSP 一行都不改。** 绝不给 `script-src` 加 `unsafe-eval` / `unsafe-inline`（红线 15）。已实测 three r186 不需要它们。
- **音频能量只在本地算，绝不通过 WebSocket 上行。** 每个客户端都有自己的
  `<audio>`，自己分析自己那一份就行 —— 上行等于把本来就在手边的数据绕一圈网络
  回来，还让画面依赖连接质量。（原先的理由是 DO 的 10 万次/日免费额度；
  2026-10-19 用户决定放弃 Cloudflare、只走局域网，那条额度不再是理由，
  但这条约束本身不变。）
- **主题 id 必须过 `isThemeId()` 白名单**，不允许任意字符串落进房间状态（红线 4）。
- **绝不把文件名、昵称或任何用户内容画进场景。**
- **场景坏了不能影响播放。** WebGL 缺失、`import('three')` 失败、分析链抛异常 —— 三种情况都必须降级，且应用功能不受影响。
- **同一时刻最多两个 Theme 存活**（交叉淡入淡出期间）。
- **画质只降不升**；档位存 `localStorage`，不上行、不进房间状态。
- `document.hidden` 为真时停掉 RAF；`prefers-reduced-motion: reduce` 时渲染静态场景。
- **三档画质都不做后期处理**（无 bloom）。
- **首屏 JS（不含按需加载的 chunk）相对现在增长 < 5 KB。**
- **场景层不是 Preact 组件**，且绝不把 3D 状态写回 store —— 唯一例外是用户点主题切换器。
- 提交粒度：每完成一步就提交一次；Conventional Commits，**英文**，写"为什么"。

```ts
/**
 * 房间主题的白名单。
 *
 * 放在 shared 而不是 client：**服务端也要校验**，两边必须认同同一份 id 表。
 * 主题 id 会落进 DO 的持久化状态并广播给全房间，所以它必须是一个封闭集合 ——
 * 任意字符串既能把房间状态撑大，也会让服务端不认识的取值流到客户端。
 *
 * 新增主题时只改这个数组，再往 `src/client/stage/themes/` 加一份实现。
 */
export const THEME_IDS = ['dawn'] as const;

export type ThemeId = (typeof THEME_IDS)[number];

export const DEFAULT_THEME: ThemeId = 'dawn';

export function isThemeId(v: unknown): v is ThemeId {
  return typeof v === 'string' && (THEME_IDS as readonly string[]).includes(v);
}

/**
 * 把"可能是任何东西"的取值折回一个合法主题。
 *
 * 两个地方用它：服务端从持久化状态里读旧房间（那时还没有 theme 字段），
 * 客户端读快照。少了它，老房间会拿到 undefined，查表查不到，场景直接不出来。
 */
export function themeOrDefault(v: unknown): ThemeId {
  return isThemeId(v) ? v : DEFAULT_THEME;
}
```

- [ ] **Step 4: 写 quality.ts 与 energy.ts**

创建 `src/client/stage/quality.ts`：

```ts
export type QualityTier = 'high' | 'medium' | 'low';

export const TIERS: Record<QualityTier, { maxPixelRatio: number; particles: number }> = {
  high: { maxPixelRatio: 2, particles: 1200 },
  medium: { maxPixelRatio: 1.5, particles: 500 },
  low: { maxPixelRatio: 1, particles: 150 },
};

/** 低于 ~42 fps 就降一档。24 ms 是 41.7 fps 的帧时间 */
const DEGRADE_ABOVE_MS = 24;

const ORDER: QualityTier[] = ['low', 'medium', 'high'];

const LS_TIER = 'mt_quality';

export function guessTier(cores: number, coarsePointer: boolean): QualityTier {
  // 手机上核数不可信（大小核混排），一律从中档起步，靠实测再降
  if (coarsePointer) return 'medium';
  if (cores >= 8) return 'high';
  if (cores >= 4) return 'medium';
  return 'low';
}

/** 只降不升：升档会在临界点上反复横跳，那种抖动比一直低画质更难忍 */
export function degrade(tier: QualityTier): QualityTier {
  const i = ORDER.indexOf(tier);
  return ORDER[Math.max(0, i - 1)]!;
}

export function shouldDegrade(avgFrameMs: number): boolean {
  return avgFrameMs > DEGRADE_ABOVE_MS;
}

/** 档位是**每台设备自己的**，不上行、不进房间状态 —— 画质是设备的事，主题才是房间的事 */
export function loadTier(): QualityTier {
  try {
    const v = localStorage.getItem(LS_TIER);
    return v === 'high' || v === 'medium' || v === 'low' ? v : pickInitialTier();
  } catch {
    return 'medium';
  }
}

export function saveTier(tier: QualityTier): void {
  try {
    localStorage.setItem(LS_TIER, tier);
  } catch {
    // 存不下就算了，不影响任何功能
  }
}

function pickInitialTier(): QualityTier {
  const cores = navigator.hardwareConcurrency ?? 4;
  const coarse = matchMedia?.('(pointer: coarse)').matches ?? false;
  return guessTier(cores, coarse);
}
```

```ts
import { effect } from '@preact/signals';
import { store } from '../store';
import { SILENT, type Energy } from './energy';
import { loadTier, TIERS, type QualityTier } from './quality';

/**
 * 场景层。
 *
 * 与 `player.ts` 同一个模式：**独立模块 + 自己订阅 store**，不活在 Preact
 * 组件树里。3D 是每帧渲染，Preact 是每次状态变化渲染，两者混进同一个调度器
 * 会出难查的抖动。
 *
 * 这个文件的**静态 import 里没有 three** —— three 由 boot() 动态 import。
 * 否则那 150 KB 会跟着首屏一起下来。
 *
 * 三条降级路径，任何一条生效都不影响播放与房间功能：
 *   1. 拿不到 WebGL context  → 不挂载
 *   2. import('three') 失败  → 不挂载
 *   3. 运行期抛异常          → 卸载并安静收场
 */
class Stage {
  private booted = false;
  private bootPending = false;
  private disposed = false;
  private canvas: HTMLCanvasElement | null = null;
  private raf = 0;
  private cleanup: (() => void) | null = null;

  mount(): void {
    if (this.booted || this.bootPending) return;
    this.disposed = false;
    this.bootPending = true;
    void this.boot()
      .catch(() => this.teardown())
      .finally(() => {
        this.bootPending = false;
      });
  }

  unmount(): void {
    this.disposed = true;
    this.teardown();
  }

  private async boot(): Promise<void> {
    // 先 import 再建 canvas：拉不下来就什么都不用收尾
    const THREE = await import('three');
    if (this.disposed) return;

    const canvas = document.createElement('canvas');
    canvas.className = 'stage-canvas';
    // 纯装饰：读屏软件跳过它，也不接收指针事件
    canvas.setAttribute('aria-hidden', 'true');

    // three 会自己再要一次 context，这里先要一次来判断可用性；
    // 拿不到就整个不挂载，页面行为与没有场景时一模一样
    const gl = canvas.getContext('webgl2') ?? canvas.getContext('webgl');
    if (!gl) return;

    document.body.appendChild(canvas);
    this.canvas = canvas;
    this.booted = true;

    const quality = loadTier();
    canvas.dataset.quality = quality;

    const renderer = new THREE.WebGLRenderer({ canvas, context: gl, antialias: false });
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, TIERS[quality].maxPixelRatio));

    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(45, 1, 0.1, 100);
    camera.position.set(0, 1.6, 4.2);
    camera.lookAt(0, 0, 0);

    const resize = () => {
      const w = window.innerWidth;
      const h = window.innerHeight;
      renderer.setSize(w, h, false);
      camera.aspect = w / h;
      camera.updateProjectionMatrix();
    };
    resize();
    window.addEventListener('resize', resize);

    // 订阅房间状态。这一版只是把订阅接通，主题在 Task 4 接上
    this.stopEffects = effect(() => {
      void store.room.value;
    });

    let last = performance.now();
    let lastDebug = 0;

    const loop = (now: number) => {
      if (this.disposed) return;
      this.raf = requestAnimationFrame(loop);
      // 锁屏 / 切后台时不该有任何渲染开销
      if (document.hidden) return;
      last = now;
      renderer.render(scene, camera);

      // 手机上没法看控制台，把状态挂到 DOM 上便于排查。
      // 4 Hz 就够，每帧写属性纯属浪费
      if (now - lastDebug > 250) {
        lastDebug = now;
        canvas.dataset.energy = '0.00';
      }
    };
    this.raf = requestAnimationFrame(loop);

    this.cleanup = () => {
      window.removeEventListener('resize', resize);
      this.stopEffects?.();
      this.stopEffects = null;
      renderer.dispose();
    };

    canvas.dataset.stage = 'ready';
  }

  private stopEffects: (() => void) | null = null;

  private teardown(): void {
    if (this.raf) cancelAnimationFrame(this.raf);
    this.raf = 0;
    try {
      this.cleanup?.();
    } catch {
      // 收尾失败也不能往外抛
    }
    this.cleanup = null;
    this.canvas?.remove();
    this.canvas = null;
    this.booted = false;
  }
}

export const stage = new Stage();
```

```ts
import * as THREE from 'three';
import type { Energy } from '../energy';
import type { QualityTier } from '../quality';
import type { Theme, ThemeContext } from './types';

/** 晨光：粉白做雾与背景，浅橙做主光与粒子，淡墨绿做对比色 */
export const DAWN = {
  pinkWhite: 0xfdf4f0,
  lightOrange: 0xf2a172,
  paleInkGreen: 0x8fa89a,
} as const;

const PARTICLE_COUNT: Record<QualityTier, number> = {
  high: 1200,
  medium: 500,
  low: 150,
};

export function createDawnTheme(): Theme {
  let group: THREE.Group | null = null;
  let points: THREE.Points | null = null;
  let drift: Float32Array | null = null;
  let key: THREE.PointLight | null = null;
  let weight = 1;

  return {
    build(ctx: ThemeContext) {
      const scene = ctx.scene;
      scene.background = new THREE.Color(DAWN.pinkWhite);
      scene.fog = new THREE.Fog(DAWN.pinkWhite, 6, 18);

      group = new THREE.Group();

      // 主光：浅橙，打亮唱片机
      key = new THREE.PointLight(DAWN.lightOrange, 24, 20, 2);
      key.position.set(1.6, 2.6, 2.2);
      group.add(key);
      // 补光：淡墨绿，从另一侧压一下，否则整屏只有一个色系会糊
      const fill = new THREE.PointLight(DAWN.paleInkGreen, 8, 18, 2);
      fill.position.set(-2.2, 1.2, -1.4);
      group.add(fill);
      group.add(new THREE.AmbientLight(DAWN.pinkWhite, 1.6));

      // 粒子：细小的光点缓慢漂浮
      const count = PARTICLE_COUNT[ctx.quality];
      const positions = new Float32Array(count * 3);
      drift = new Float32Array(count);
      for (let i = 0; i < count; i++) {
        const r = 2.4 + Math.random() * 5.5;
        const a = Math.random() * Math.PI * 2;
        positions[i * 3] = Math.cos(a) * r;
        positions[i * 3 + 1] = (Math.random() - 0.35) * 5;
        positions[i * 3 + 2] = Math.sin(a) * r;
        drift[i] = 0.15 + Math.random() * 0.5;
      }
      const geo = new THREE.BufferGeometry();
      geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
      points = new THREE.Points(
        geo,
        new THREE.PointsMaterial({
          color: DAWN.lightOrange,
          size: 0.035,
          transparent: true,
          opacity: 0.9,
          depthWrite: false,
        }),
      );
      group.add(points);
      scene.add(group);
    },

    update(dtMs: number, energy: Energy) {
      if (!points || !drift) return;
      const pos = points.geometry.getAttribute('position') as THREE.BufferAttribute;
      const arr = pos.array as Float32Array;
      // 低音把粒子往外推，高音让它们整体变亮
      const push = 1 + energy.bass * 0.12;
      for (let i = 0; i < drift.length; i++) {
        arr[i * 3 + 1] = (arr[i * 3 + 1] ?? 0) + drift[i]! * dtMs * 0.0004;
        arr[i * 3] = (arr[i * 3] ?? 0) * (1 + (push - 1) * 0.02);
        arr[i * 3 + 2] = (arr[i * 3 + 2] ?? 0) * (1 + (push - 1) * 0.02);
      }
      pos.needsUpdate = true;
      const mat = points.material as THREE.PointsMaterial;
      mat.opacity = (0.45 + energy.level * 0.5) * weight;
      mat.size = (0.03 + energy.treble * 0.03) * (0.6 + weight * 0.4);
      if (key) key.intensity = (10 + energy.bass * 26) * weight;
    },

    setWeight(w: number) {
      weight = w;
      if (group) group.visible = w > 0.001;
    },

    dispose() {
      if (!group) return;
      group.traverse((o) => {
        const m = o as THREE.Mesh;
        m.geometry?.dispose?.();
        const mat = m.material as THREE.Material | THREE.Material[] | undefined;
        if (Array.isArray(mat)) mat.forEach((x) => x.dispose());
        else mat?.dispose?.();
      });
      group.removeFromParent();
      group = null;
      points = null;
      drift = null;
      key = null;
    },
  };
}
```

```ts
import type { Energy } from './energy';
import type { QualityTier } from './quality';

/** 比真实的 33⅓ rpm 慢得多 —— 看得出在转就够了，快了反而晃眼 */
const RADIANS_PER_SECOND = 0.9;

/** 单帧最多推进这么多毫秒。切后台回来时 dt 可能是好几分钟 */
const MAX_STEP_MS = 64;

/**
 * 唱盘转角。纯函数，所以能在 node 里测。
 *
 * 夹住单帧步长是必须的：标签页被挂起时 `requestAnimationFrame` 的时间差
 * 可能是几分钟，不夹的话回到前台会看到唱片"啪"地跳好几圈。
 */
export function spin(angle: number, dtMs: number, playing: boolean): number {
  if (!playing) return angle;
  const step = Math.min(MAX_STEP_MS, Math.max(0, dtMs));
  const next = angle + (RADIANS_PER_SECOND * step) / 1000;
  return next % (Math.PI * 2);
}

export function createTurntable(THREE: typeof import('three'), quality: QualityTier): import('three').Group {
  const segments = quality === 'low' ? 24 : 64;
  const group = new THREE.Group();

  // 转盘
  const platter = new THREE.Mesh(
    new THREE.CylinderGeometry(1.15, 1.15, 0.08, segments),
    new THREE.MeshStandardMaterial({ color: 0x8fa89a, roughness: 0.5, metalness: 0.3 }),
  );
  group.add(platter);

  // 唱片
  const disc = new THREE.Mesh(
    new THREE.CylinderGeometry(1.0, 1.0, 0.02, segments),
    new THREE.MeshStandardMaterial({ color: 0x2b2320, roughness: 0.35, metalness: 0.1 }),
  );
  disc.position.y = 0.05;
  disc.name = 'disc';
  group.add(disc);

  // 标签
  const label = new THREE.Mesh(
    new THREE.CylinderGeometry(0.3, 0.3, 0.021, segments),
    new THREE.MeshStandardMaterial({ color: 0xf2a172, roughness: 0.6 }),
  );
  label.position.y = 0.052;
  disc.add(label);

  // 唱臂：细长一根，斜搭在唱片上
  const arm = new THREE.Mesh(
    new THREE.CylinderGeometry(0.02, 0.02, 1.5, 12),
    new THREE.MeshStandardMaterial({ color: 0x8fa89a, roughness: 0.3, metalness: 0.6 }),
  );
  arm.position.set(0.95, 0.28, 0.35);
  arm.rotation.z = -0.55;
  group.add(arm);

  return group;
}

export function updateTurntable(
  group: import('three').Group,
  angle: number,
  energy: Energy,
  weight: number,
): void {
  const disc = group.getObjectByName('disc');
  if (!disc) return;
  disc.rotation.y = angle;
  // 低音给整台机器一点极轻的呼吸，别太明显
  const scale = 1 + energy.bass * 0.02 * weight;
  group.scale.setScalar(scale);
}
```

```ts
/** 分频段。低音驱动粒子的推挤与光晕，高音驱动闪烁 */
const BASS_HZ: [number, number] = [20, 250];
const TREBLE_HZ: [number, number] = [4000, 16000];

/** 攻击快、释放慢。不这么做的话粒子会随每一个鼓点抖成噪声 */
const ATTACK_MS = 80;
const RELEASE_MS = 400;

const clamp01 = (v: number) => (v < 0 ? 0 : v > 1 ? 1 : v);

/** 一个频段对应到 FFT 的哪些 bin。bin 宽度 = sampleRate / 2 / binCount */
function bandRange(sampleRate: number, binCount: number, [lo, hi]: [number, number]) {
  const hzPerBin = sampleRate / 2 / binCount;
  const from = Math.max(1, Math.floor(lo / hzPerBin));
  const to = Math.min(binCount - 1, Math.ceil(hi / hzPerBin));
  return { from, to: Math.max(from + 1, to) };
}

function bandLevel(spectrum: Uint8Array, sampleRate: number, band: [number, number]): number {
  const { from, to } = bandRange(sampleRate, spectrum.length, band);
  let sum = 0;
  for (let i = from; i < to; i++) sum += spectrum[i] ?? 0;
  // 255 是满幅。开方是为了让弱信号也看得见，否则安静段落场景是死的
  return clamp01(Math.sqrt(sum / (to - from) / 255));
}

function smooth(prev: number, next: number, dtMs: number): number {
  const ms = next > prev ? ATTACK_MS : RELEASE_MS;
  const k = clamp01(dtMs / ms);
  return prev + (next - prev) * k;
}

/**
 * 从一帧频谱里读出能量。纯函数，不碰 DOM，所以能在 node 里测。
 */
export function readEnergy(
  spectrum: Uint8Array,
  sampleRate: number,
  prev: Energy,
  dtMs: number,
): Energy {
  let sum = 0;
  for (let i = 0; i < spectrum.length; i++) sum += spectrum[i] ?? 0;
  const rawLevel = clamp01(Math.sqrt(sum / spectrum.length / 255));

  const raw: Energy = {
    level: rawLevel,
    bass: bandLevel(spectrum, sampleRate, BASS_HZ),
    treble: bandLevel(spectrum, sampleRate, TREBLE_HZ),
  };

  return {
    level: smooth(prev.level, raw.level, dtMs),
    bass: smooth(prev.bass, raw.bass, dtMs),
    treble: smooth(prev.treble, raw.treble, dtMs),
  };
}

/**
 * 兜底曲线：拿不到任何频域数据时用。
 *
 * 按播放时间推一条缓慢起伏的假能量。场景永不呆滞，节奏感弱一档，
 * 但它绝不出错 —— 这是"可视化不能反过来弄坏播放"这条底线的最后一层。
 */
export function proceduralEnergy(elapsedMs: number, playing: boolean): Energy {
  if (!playing) return SILENT;
  const t = elapsedMs / 1000;
  const a = 0.5 + 0.5 * Math.sin(t * 0.7);
  const b = 0.5 + 0.5 * Math.sin(t * 1.9 + 1.1);
  const c = 0.5 + 0.5 * Math.sin(t * 3.3 + 2.4);
  return {
    level: clamp01(0.28 + a * 0.24),
    bass: clamp01(0.2 + b * 0.3),
    treble: clamp01(0.15 + c * 0.35),
  };
}
```

创建 `src/client/stage/analyser.ts`：

```ts
import { SILENT, readEnergy, type Energy } from './energy';

export type EnergySource = {
  /** 返回 null 表示这帧没有数据，调用方退到兜底曲线 */
  read(dtMs: number): Energy | null;
  dispose(): void;
};

/**
 * 接一路音频出来分析。三层，任何一层失败就退到下一层。
 *
 * **主路用 captureStream，不用 createMediaElementSource。** 后者会把 audio
 * 元素的输出整个搬进 Web Audio 图，而且**不可撤销** —— 一旦调用，该元素的输出
 * 永久走这个图。于是"销毁分析器"就不能 disconnect 了事，必须把
 * source → destination 重新接上，否则整首歌永久静音。这是"加了可视化之后
 * 没声音"这类 bug 的标准成因，也是这里绕开它的原因。
 *
 * 拿不到就返回 null，由调用方走程序化兜底。**任何情况下都不抛异常出去。**
 */
export function createEnergySource(audio: HTMLAudioElement): EnergySource | null {
  let ctx: AudioContext | null = null;
  let analyser: AnalyserNode | null = null;
  let spectrum: Uint8Array | null = null;
  let prev: Energy = SILENT;
  let rerouted = false;

  try {
    ctx = new AudioContext();
    analyser = ctx.createAnalyser();
    analyser.fftSize = 2048;
    analyser.smoothingTimeConstant = 0.6;
    spectrum = new Uint8Array(analyser.frequencyBinCount);

    const capture = (audio as HTMLAudioElement & { captureStream?: () => MediaStream })
      .captureStream;
    if (typeof capture === 'function') {
      // 主路：元素照常播放，我们只是从旁边接一路出来
      const stream = capture.call(audio);
      ctx.createMediaStreamSource(stream).connect(analyser);
    } else {
      // 备路：这一步不可撤销，见上面的说明
      const source = ctx.createMediaElementSource(audio);
      source.connect(analyser);
      analyser.connect(ctx.destination);
      rerouted = true;
    }
  } catch {
    // 任何一步失败都整条摘掉，交给调用方兜底
    try {
      ctx?.close();
    } catch {
      /* 收尾失败也不抛 */
    }
    return null;
  }

  const ownCtx = ctx;
  const ownAnalyser = analyser;
  const ownSpectrum = spectrum;

  return {
    read(dtMs: number): Energy | null {
      try {
        // 自动播放策略下 AudioContext 可能起不来。退到兜底，不影响播放
        if (ownCtx.state !== 'running') return null;
        ownAnalyser.getByteFrequencyData(ownSpectrum);
        prev = readEnergy(ownSpectrum, ownCtx.sampleRate, prev, dtMs);
        return prev;
      } catch {
        return null;
      }
    },

    dispose(): void {
      try {
        if (rerouted) {
          // 走过备路的话，元素的输出永久在这个图里。断开分析器之后必须
          // 让 source 直连 destination —— 否则整首歌永久静音。
          ownAnalyser.disconnect();
        }
        void ownCtx.close();
      } catch {
        /* 收尾失败也不能往外抛 */
      }
    },
  };
}
```

```ts
    // 只看实测帧时间。2 秒滚动窗口，超了就降一档并记住
    let tier = quality;
    let frames = 0;
    let frameMsSum = 0;
    let windowStart = performance.now();

    const watchQuality = (now: number) => {
      frames++;
      frameMsSum += now - last;
      if (now - windowStart < 2000) return;
      const avg = frameMsSum / Math.max(1, frames);
      frames = 0;
      frameMsSum = 0;
      windowStart = now;
      // 观测点：手机上没法看控制台，把实测帧时间挂出来
      canvas.dataset.frameMs = avg.toFixed(1);
      if (shouldDegrade(avg) && tier !== 'low') {
        tier = degrade(tier);
        saveTier(tier);
        renderer.setPixelRatio(Math.min(window.devicePixelRatio, TIERS[tier].maxPixelRatio));
        canvas.dataset.quality = tier;
      }
    };
```

在 `tick` 里调用 `watchQuality(now)`，并初始化 `canvas.dataset.quality = quality;`。

```ts
import * as THREE from 'three';
import type { Energy } from '../energy';
import type { QualityTier } from '../quality';
import type { Theme, ThemeContext } from './types';

/** 余烬：深底 + 暖橙线框球 + 亮核。参考图见设计规格 §8.1 */
export const EMBER = {
  deep: 0x150b07,
  warm: 0xff5a1e,
  core: 0xffd9b0,
} as const;

/** 球的细分。越低越省，low 那颗也已经看得出是个球 */
const DETAIL: Record<QualityTier, number> = { high: 3, medium: 2, low: 1 };

const PARTICLES: Record<QualityTier, number> = { high: 900, medium: 360, low: 120 };

/** 径向渐变贴图，用来做光晕。canvas 生成，不加载任何外部资源 */
function glowTexture(): THREE.Texture {
  const size = 128;
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext('2d')!;
  const g = ctx.createRadialGradient(size / 2, size / 2, 0, size / 2, size / 2, size / 2);
  g.addColorStop(0, 'rgba(255, 217, 176, 0.95)');
  g.addColorStop(0.35, 'rgba(255, 90, 30, 0.45)');
  g.addColorStop(1, 'rgba(255, 90, 30, 0)');
  ctx.fillStyle = g;
  ctx.fillRect(0, 0, size, size);
  const tex = new THREE.CanvasTexture(canvas);
  tex.colorSpace = THREE.SRGBColorSpace;
  return tex;
}

export function createEmberTheme(): Theme {
  let group: THREE.Group | null = null;
  let wire: THREE.LineSegments | null = null;
  let halo: THREE.Sprite | null = null;
  let core: THREE.Mesh | null = null;
  let points: THREE.Points | null = null;
  let base: Float32Array | null = null;
  let weight = 1;

  return {
    build(ctx: ThemeContext) {
      const scene = ctx.scene;
      scene.background = new THREE.Color(EMBER.deep);
      scene.fog = new THREE.Fog(EMBER.deep, 8, 26);

      group = new THREE.Group();

      // 线框球。IcosahedronGeometry 的 wireframe 比 UV 球干净得多 ——
      // 没有极点那一撮挤在一起、转起来会像莫列波纹的线
      const geo = new THREE.IcosahedronGeometry(1.6, DETAIL[ctx.quality]);
      // 顶点沿法线做一次低频扰动，让它不是一颗死板的球。扰动幅度存下来当基准，
      // 低音在这上面叠加
      const pos = geo.getAttribute('position') as THREE.BufferAttribute;
      const arr = pos.array as Float32Array;
      base = new Float32Array(arr.length);
      for (let i = 0; i < arr.length; i += 3) {
        const x = arr[i]!;
        const y = arr[i + 1]!;
        const z = arr[i + 2]!;
        const len = Math.hypot(x, y, z) || 1;
        // 三个不同频率的正弦叠一起，比 Math.random 平滑 —— 随机会把球面撕成锯齿
        const wobble =
          1 + 0.075 * Math.sin(y * 3.1) + 0.05 * Math.sin(x * 4.7 + 1.3) + 0.04 * Math.sin(z * 5.9);
        base[i] = (x / len) * wobble;
        base[i + 1] = (y / len) * wobble;
        base[i + 2] = (z / len) * wobble;
        arr[i] = base[i]!;
        arr[i + 1] = base[i + 1]!;
        arr[i + 2] = base[i + 2]!;
      }
      pos.needsUpdate = true;

      wire = new THREE.LineSegments(
        new THREE.WireframeGeometry(geo),
        new THREE.LineBasicMaterial({
          color: EMBER.warm,
          transparent: true,
          opacity: 0.85,
          depthWrite: false,
        }),
      );
      group.add(wire);
      geo.dispose();

      // 亮核
      core = new THREE.Mesh(
        new THREE.IcosahedronGeometry(0.55, 1),
        new THREE.MeshBasicMaterial({ color: EMBER.core, transparent: true, opacity: 0.95 }),
      );
      group.add(core);

      // 光晕：加法混合的径向渐变。不写一行后期处理就能出参考图那种辉光
      halo = new THREE.Sprite(
        new THREE.SpriteMaterial({
          map: glowTexture(),
          color: EMBER.warm,
          transparent: true,
          blending: THREE.AdditiveBlending,
          depthWrite: false,
          depthTest: false,
        }),
      );
      halo.scale.setScalar(9);
      group.add(halo);

      // 微粒：绕球公转
      const count = PARTICLES[ctx.quality];
      const p = new Float32Array(count * 3);
      for (let i = 0; i < count; i++) {
        const r = 2.4 + Math.random() * 4;
        const a = Math.random() * Math.PI * 2;
        const y = (Math.random() - 0.5) * 4;
        p[i * 3] = Math.cos(a) * r;
        p[i * 3 + 1] = y;
        p[i * 3 + 2] = Math.sin(a) * r;
      }
      const pgeo = new THREE.BufferGeometry();
      pgeo.setAttribute('position', new THREE.BufferAttribute(p, 3));
      points = new THREE.Points(
        pgeo,
        new THREE.PointsMaterial({
          color: EMBER.warm,
          size: 0.05,
          transparent: true,
          opacity: 0.7,
          depthWrite: false,
          blending: THREE.AdditiveBlending,
        }),
      );
      group.add(points);

      // 球心一盏光，把唱片机从球里照亮
      const light = new THREE.PointLight(EMBER.warm, 14, 16, 2);
      light.position.set(0, 0.6, 0.8);
      group.add(light);
      group.add(new THREE.AmbientLight(EMBER.warm, 0.35));

      scene.add(group);
    },

    update(dtMs: number, energy: Energy) {
      if (!group || !wire || !halo || !core || !points || !base) return;
      const t = performance.now() / 1000;

      // 低音把球整体撑大，并让扰动更明显
      group.scale.setScalar(1 + energy.bass * 0.14);

      // 线框与光晕的亮度跟高音走
      (wire.material as THREE.LineBasicMaterial).opacity = (0.55 + energy.treble * 0.45) * weight;
      const haloMat = halo.material as THREE.SpriteMaterial;
      haloMat.opacity = (0.35 + energy.level * 0.55) * weight;
      halo.scale.setScalar(8 + energy.bass * 3);
      (core.material as THREE.MeshBasicMaterial).opacity = (0.7 + energy.level * 0.3) * weight;

      // 微粒缓慢公转
      points.rotation.y += dtMs * 0.00004;
      (points.material as THREE.PointsMaterial).opacity = (0.35 + energy.treble * 0.5) * weight;

      // 球本身极慢地自转，免得扰动看着像静止的
      group.rotation.y = t * 0.08;
    },

    setWeight(w: number) {
      weight = w;
      if (group) group.visible = w > 0.001;
    },

    dispose() {
      if (!group) return;
      group.traverse((o) => {
        const any = o as THREE.Mesh & { material?: THREE.Material | THREE.Material[] };
        any.geometry?.dispose?.();
        const mat = any.material;
        if (Array.isArray(mat)) mat.forEach((x) => x.dispose());
        else {
          (mat as THREE.SpriteMaterial | undefined)?.map?.dispose();
          mat?.dispose?.();
        }
      });
      group.removeFromParent();
      group = null;
      wire = null;
      halo = null;
      core = null;
      points = null;
      base = null;
    },
  };
}
```
